# Global Volume and BatchNorm trial — 2026-11-01 (SGT)

The Global Volume trial passed: the pinned validation inputs were copied from the
regional network volume, mounted on the requested PRO 6000 MIG 24GB in an available
US region, staged and hash-verified locally, and used for all ten complete songs.
Both compute Pods were deleted; both storage volumes remain.

The four-cell intervention identifies **BN running buffers as the dominant source
of the observed step-90 regression**. Restoring official running statistics recovers
most of the loss. Putting the learned statistics into otherwise official weights
reproduces the collapse. This does not identify why training produced those buffers,
and learned parameters with restored buffers are not an established improvement.

## Storage, runtime and acceptance

- Snapshot: 58 files, 4,158,217,826 bytes (3.87 GiB), including 50 validation WAVs,
  provenance and the exact step-90 backup. Source data is retained. This is not a
  full copy of the 100-song training pool or a complete offsite training backup.
- The CPU copy reported 19.32 seconds including destination read-back; its actual
  rate was $0.06/hour. The source-region CPU Pod was deleted after approximately
  34 seconds from the controller's creation log.
- The MIG Pod's actual rate was $0.69/hour. Its observed creation-to-cleanup span
  was approximately 6 minutes 19 seconds, including dependency installation,
  first cross-region reads and local staging. The evaluation timer was
  80.92 seconds, excluding staging, with 7.36 GiB peak allocated CUDA memory.
- Estimated combined compute from these observed spans is about $0.074, not an
  invoice. Container storage, retained Global Volume storage and request charges
  are additional. This is not a controlled throughput/cost comparison with 4090.
- Runtime identity: one Blackwell device, compute capability 12.0, 25,367,150,592
  visible bytes; PyTorch 2.8.0+cu128 and CUDA 12.8. TF32 remains disabled.
- All 160 song/stem/variant scores are finite. Checkpoint/tensor fingerprints,
  unchanged-state checks, full-song lengths, input hashes, recomputed summaries
  and export checksums passed both the runner and a second local artifact check.
- The two unmodified controls reproduce the earlier 4090 aggregate means/medians:
  maximum absolute deviation 2.33804034e-07 dB, below the predeclared 0.001 dB gate.
- Global storage contains input objects only. File locks and evaluation outputs
  use the local disk. The completion marker is written after read-back validation,
  and the consumer mounts only after the copy job finishes.

## Follow-up experiment

**Update:** The [matched frozen-BN training pilot](frozen-bn-41230412543.md) has now
completed. The paragraph below records the proposal made after this intervention.

Run a separate training pilot from the same official initialization with BN running
statistics frozen, preserving the training data/split, seed, step budget and learning
rate. Keep ordinary dropout training behavior explicit. Then compare full-song
SI-SDR, BSSEval-v4 SDR and listening samples before promoting any weights. This
training experiment has not been run; post-hoc buffer replacement is not evidence
that frozen-BN training will improve the baseline.
