# Matched frozen-BN training pilot — 2026-11-01 (SGT)

Freezing BatchNorm statistics during the matched 90-step pilot avoids the severe
ordinary-BN regression. Frozen training beats ordinary training on all ten songs
for every stem under both metrics. It does **not establish an improvement over
official initialization**: all four median paired changes remain slightly negative
under both metrics. Keep official converted weights as the inference baseline.

## Controlled recipe and checks

The two independent runs use identical official initialization, the pinned 90/10
project split, seed 17, batch size 1, one crop per training song, one epoch / 90
optimizer updates, Adam at 1e-5 with epsilon 1e-8, gradient clipping 5, FP32,
deterministic execution and no TF32. The 50-song test pool remains unused.
Both arms run on the same PRO 6000 MIG 24GB, PyTorch 2.8.0+cu128 / CUDA 12.8.

`--freeze-bn-stats` puts only BN layers in eval mode during training. Their stored
official moments are used in the forward pass and remain unchanged; BN affine
parameters still train, and dropout stays active. This changes forward
normalization as well as buffer updates, so the training intervention does not
isolate buffer writes alone.

- Both arms completed all 90 finite optimizer updates, with no skipped update.
  Data/config signatures and final CPU/CUDA RNG states match across arms.
- Frozen BN buffers exactly match initialization; ordinary buffers change.
  Affine and other model parameters change in both arms.
- One-crop validation spectral loss is 6.992374 for normal and 1.343880 for frozen.
  This loss is not SDR and does not establish better separation quality.
- Training timers are 29.85 seconds (normal) and 30.72 seconds (frozen), with about
  1.04 GiB peak allocated CUDA memory. These timers exclude staging and scoring.
- Full-song inference/scoring totals 1,524.96 seconds; peak allocated CUDA memory
  is 7.22 GiB. All 120 song/stem/variant SI-SDR scores are finite. BSSEval has
  1,351 finite and 466 undefined frames per stem/variant, out of 1,817 frames;
  coverage matches across models, and all song-level aggregates are finite.
- Official baseline aggregate means/medians reproduce the earlier evaluation
  within 0.00000135 dB, below the predeclared 0.001 dB gate. The new normal arm
  also agrees closely with the historical normal arm (maximum mean/median
  deviation 0.00005293 dB); this latter comparison is descriptive.
- Full lengths, source hashes, recomputed paired summaries, checkpoint state,
  result archive hashes and audio sample values passed runner-side and independent
  local artifact validation. Evaluation leaves model state unchanged.

## Interpretation and next decision

The frozen policy is a viable way to avoid the observed short-pilot collapse, but
these 90 updates do not justify promoting its weights or claiming convergence.
Further work should retain the official baseline and use a predeclared training
budget and learning-rate comparison with the frozen policy, tracking all four
stems on this validation split before a final untouched-test evaluation.
